# Tayda A-5118 - Pink Plastic Knob with Pointer

## Description

Pink plastic pointer-style (chickenhead) knob with a raised indicator line for easy position reading. 16mm bottom diameter tapering to 12mm at the top, 17mm tall. Fits standard 6mm T18 split-shaft potentiometers. The pointer style makes it easy to see the exact position of a control at a glance.

Popular for color-coding controls on Eurorack panels, mixer boards, and effects pedals. The orange counterpart (A-5116) is in Section C of the same bin.

## Specifications

### Physical Characteristics

- **Color**: Pink
- **Material**: Plastic (soft-touch)
- **Diameter (bottom)**: 16mm
- **Diameter (top)**: 12mm
- **Height**: 17mm
- **Shaft Type**: T18 Split Shaft (spline)
- **Shaft Hole**: 6mm
- **Mounting**: Push-fit

### Key Features

- Pointer/indicator line for precise position reading
- Tapered chickenhead profile
- Bright pink color for panel color-coding
- Soft-touch plastic material
