# Tayda A-5116 - Orange Plastic Knob with Pointer

## Description

Orange plastic pointer-style (chickenhead) knob with a raised indicator line for easy position reading. Fits standard 6mm T18 split-shaft potentiometers. The pointer profile makes it easy to read exact control positions on a panel.

Popular for color-coding controls on Eurorack panels, mixer boards, and effects pedals. The pink counterpart (A-5118) is in Section B of the same bin.

## Specifications

### Physical Characteristics

- **Color**: Orange
- **Material**: Plastic (soft-touch)
- **Diameter (bottom)**: ~16mm
- **Height**: ~15mm
- **Shaft Type**: T18 Split Shaft (spline)
- **Shaft Hole**: 6mm x 18T
- **Mounting**: Push-fit

### Key Features

- Pointer/indicator line for precise position reading
- Tapered chickenhead profile
- Bright orange color for panel color-coding
- Soft-touch plastic material
