# Component Sets & Assortment Kits

Through-hole component assortment kits stored together. Includes resistors, polyester film capacitors, and electrolytic capacitors.

## ELEGOO Resistor Assortment Kit

- **Brand**: ELEGOO
- **Type**: Through-hole resistors
- **Contains**: 5-color band (1% metal film) and 4-color band (5% carbon film) resistors
- **Qty per value**: ~50 pcs
- **Tolerance**: 1% (5-band) and 5% (4-band)
- **Storage**: Clear plastic compartment box

### Values — 5-Color Band (1% Metal Film)

Common E24/E96 values from 1Ω through ~1MΩ, 50pcs each.

### Values — 4-Color Band (5% Carbon Film)

Common E12 values, 50pcs each.
