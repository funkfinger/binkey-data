# Tayda A-6887 - Black Rotary Encoder Knob, D-Shaft 6x4.5mm

## Description

Black soft-touch rubber encoder knob designed for 6mm D-shaft rotary encoders. The D-shaft bore ensures the knob won't slip or rotate on the shaft. Compact profile makes it ideal for Eurorack panels and dense PCB layouts.

Pairs directly with the Tayda A-6331 EC11 rotary encoder (Cabinet 3, Bin 32, Section E). The green counterpart (A-7022) is in Cabinet 7, Bin 15, Section B.

## Specifications

### Physical Characteristics

- **Color**: Black
- **Material**: Soft-touch rubber
- **Diameter (bottom)**: 15mm
- **Height**: 16.1mm
- **Shaft Type**: D-Shaft (flatted)
- **Shaft Hole**: 6mm x 4.5mm flat
- **Mounting**: Push-fit (friction/press-on)

### Key Features

- Soft-touch rubber for comfortable feel
- D-shaft bore prevents slipping
- Compact size suits Eurorack and panel-mount applications
- No set screw required

## Circuit Examples

### Installation

```
Press knob D-bore onto 6mm D-shaft of encoder.
Flat of bore aligns with flat of shaft — only fits one way.
No tools or set screw required.
```

## Technical Notes

- Only fits D-shaft encoders — will not fit spline or round shafts
- Press firmly until knob is seated flush against panel or encoder body
- Green version (A-7022) is identical in size and fits same shaft
